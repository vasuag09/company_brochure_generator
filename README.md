# 🧠 Gemini-Powered Company Brochure Generator

This is a simple Gradio web app that uses **Google Gemini 2.5 Flash API** to generate a professional **company brochure** from a company's landing page URL and name. The response is streamed live for better UX.

---

## 🚀 Features

- 🔎 Scrapes and parses the content of a company's landing page
- 💡 Sends the parsed content + company name to Gemini 2.5 for brochure generation
- 🔁 Streams response in real-time to the UI
- 🖱️ Submit button disables during processing for a clean experience

---

## 🛠️ Tech Stack

- [Gradio](https://www.gradio.app/) for UI
- [Google Gemini 2.5 API (Flash model)](https://ai.google.dev/)
- `requests` for fetching website content
- Python 3.10+
